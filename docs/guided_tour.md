# Guided walkthrough — 4C Insight

The **Guided walkthrough** button in the sidebar starts a read-only tour of the main analysis pages. **Tour this tab** shows only the current workflow. The tour can run before a user loads any files.

## Controls

- **Next** and **Back** move through steps.
- **Skip tour**, **Finish**, the Close button, or **Escape** end the tour.
- **Right Arrow** and **Left Arrow** move between steps. **Tab** stays inside the tour controls while the tour is open.
- The application returns to the workspace and integrative subview that were open when the tour began.

The tour explains Project, Sample Metadata, Explore & QC, Compare Groups, Results, Longitudinal, Integrative Analysis (Overview, Details, Pathways), History, Docs, Settings, and state save/load controls. It uses stable navigation targets when sample-level results have not been calculated.

## Scientific and privacy contract

Tour navigation changes only the visible page and subview. It does not run analyses, read files, change scientific settings, upload data, clear the session, save portable state, or change History entries. Real analyses remain browser-local and require the user's actions. The tour describes descriptive and exploratory interpretation limits, including the fact that a pathway-network edge does not prove physical interaction.
