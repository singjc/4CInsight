# 4C Insight

**4C Insight** is a browser-based tool to **process and analyze multi-omics cohort data**. It helps researchers compare measurements across samples, patients, and time points.

## What it does

- Import local gene and transcript expression, BCR and TCR repertoire, BCR isotype, and immune infiltration data.
- Review data quality, organize sample metadata, compare groups, and analyze longitudinal changes.
- Integrate seven data types to explore shared sample patterns and clusters.
- Run pathway enrichment and inspect supporting genes and gene-sharing networks.

## Privacy

Analysis runs on your device with Rust and WebAssembly. Original cohort files are not uploaded to an analysis server. You can save results locally.
